Pseudocode Fundamentals

Understanding informal, language-agnostic algorithm representations and converting them to Python.

What is Pseudocode?

Pseudocode is an informal, human-readable outline of a computer program or algorithm. It uses structured plain English rather than strict programming syntax so developers can design logic without worrying about language-specific rules.

Standard Pseudocode Conventions vs. Python Syntax

Operation Standard Pseudocode Keyword / Format Python Equivalent
Input INPUT age or READ age age = input()
Output OUTPUT "Hello" or PRINT "Hello" print("Hello")
Assignment SET score TO 100 or score ← 100 score = 100
Selection IF score >= 50 THEN
  OUTPUT "Pass"
ELSE
  OUTPUT "Fail"
ENDIF 		if score >= 50:
    print("Pass")
else:
    print("Fail")
Pre-test Loop WHILE count < 5 DO
  count ← count + 1
ENDWHILE 		while count < 5:
    count += 1
Counted Loop FOR i ← 1 TO 5 STEP 1
  OUTPUT i
ENDFOR 		for i in range(1, 6):
    print(i)

Pseudocode Algorithm Example

Pseudocode Algorithm

BEGIN
  SET total TO 0
  FOR count FROM 1 TO 3
    INPUT num
    SET total TO total + num
  ENDFOR
  OUTPUT "Sum: ", total
END

Python Implementation

total = 0
for count in range(1, 4):
    num = int(input("Enter number: "))
    total += num

print(f"Sum: {total}")
Exam Tip: Always look out for explicit loop delimiters in pseudocode like ENDIF, ENDWHILE, and ENDFOR. Python replaces these block endings with indentation!

Python Recap

Lists vs. Tuples

# Lists use [] and are mutable
fruits = ['apple', 'banana']
fruits.append('cherry')
fruits[0] = 'avocado'  # Allowed

# Tuples use () and are immutable
coords = (10, 20)
# coords[0] = 15  --> Raises TypeError!

Key Takeaways

  • Use Lists when data will grow, shrink, or change.
  • Use Tuples for static records that must not be altered accidentally.

Pre-Test Loops & Conditionals

# Pre-test loop checking condition first
count = 0
while count < 3:
    print(f"Count: {count}")
    count += 1

for item in fruits:
    if item == 'banana':
        print("Found!")

Behavior Rules

  • If a while loop condition starts as False, the body runs 0 times.
  • for loops automatically iterate through sequences like lists or tuples.

Files & Exception Handling

Handling external files safely and managing runtime errors without program crashes.

File Access Modes

"r" Read Mode

  • Default file mode.
  • Opens file for reading only.
  • Raises FileNotFoundError if missing.

"w" Write Mode

  • Opens file for writing.
  • Overwrites existing content completely.
  • Creates file if non-existent.

"a" Append Mode

  • Opens file for writing.
  • Appends new data at the end.
  • Preserves existing file content.

File Reading Methods

read()

Reads the whole file as a single string.

readline()

Reads one line at a time as a string.

readlines()

Reads all lines into a list of strings.

Exception Handling (try-except-finally)

Structure Overview

  • try: Encloses risky code that might throw an error.
  • except: Executes if a specific error occurs.
  • finally: Always executes regardless of errors.
try:
    f = open('data.txt', 'r')
    text = f.read()
except FileNotFoundError:
    print("File not found!")
finally:
    print("Always runs!")  # Cleanup code

Common Coding Patterns

Frequent code snippets and patterns tested in exam questions.

1. Context Manager (with)

# Automatically closes file when block ends
with open("log.txt", "a") as f:
    f.write("New log entry\n")

2. Multiple Exception Catching

try:
    val = int(input("Number: "))
    res = 10 / val
except (ValueError, ZeroDivisionError) as e:
    print(f"Invalid operation: {e}")

3. Safe File Reading

try:
    f = open("info.txt", "r")
    data = f.readlines()
    f.close()
except FileNotFoundError:
    data = []

4. Iterating List of Tuples

records = [("Alice", 90), ("Bob", 85)]
for name, score in records:
    print(f"{name}: {score}")
Exam Note: Files opened manually via open() must always be closed using close() or scoped within a with context block.
